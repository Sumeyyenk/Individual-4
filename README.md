# Turn-Based RPG Combat Engine (OOP Demo)

A C# console application demonstrating core Object-Oriented Programming principles—including polymorphism, inheritance, and interface abstraction—through a modular combat simulation.

## Features
- Interface Implementation: Uses an `IDestructible` interface to handle shared damage logic across distinct entity types (characters and environment objects).
- Polymorphism & Inheritance: Implements an abstract `Character` base class extended by specialized subclasses (`Warrior`, `Mage`) with unique attack behaviors.
